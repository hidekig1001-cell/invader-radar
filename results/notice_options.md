# 盤が大きくなる面のお知らせを、もっと派手に分かりやすくする案（10/27、クラウドセッション。main 0ae3435）

ユーザーの声（10/27 15:5x）: 「１１７８　もっとはでに見た目がわかりやすく。」

## 1. 今のお知らせの作り
- **出すところ**:
  - scenes/main.gd。次の面に進むと、`_refresh` でクリアの文を消し、`size_up_tile_text()` が空でなければ `size_up_wait = 0.6` にする。
  - `_process` → `tick_size_up(delta)` で 0.6 秒たつと `bubble.show_tile(size_up_tile_text(), 盤の中心)` を呼ぶ。
  - 出てから `size_up_age` を数え、0.8 秒たつまではタップで消さない（`_on_touch_down`）。以上が CR-1172・CR-1178 の作り。
- **見た目**: scenes/message_bubble.gd の `show_tile`。
  - 大きさと場所: 900×160 のタイルを、盤の中心から 200 下に出す。
  - 色: 淡いピンクの地 Color8(255, 205, 222)、縁 Color8(232, 150, 180)・太さ 4・角の丸み 24（`clear_tile_box`）。字は濃い茶色、縁取り無し。
  - 文: 日本語なら「この面からはマスが 5×5 になるよ。\nがんばって！  タップではじめる」の 2 行。
  - 字の大きさ: show_tile では決めていない。その前の吹き出しの大きさを引き継ぐ（多くは 52 まで）。
- **出方と消え方**:
  - パッと出るだけで、動き・音・振動は無い。タップで `clear_text()` して消え、操作の説明の吹き出しに戻る。
  - **面のクリアの「クリア！ タップで次の面」も、同じ show_tile の同じピンクのタイル**。2 つの見分けが付かず、続けて出るので「また同じ札が出た」に見えやすい。これが「分かりにくい」の元と見る。

## 2. 案 3 つ

### 案 A「金色のタイルがぽんと弾む（音と振動つき）」 — 手間: 小
- **見た目**:
  - お知らせのタイルだけを、金色の地 Color8(255, 215, 64)・太い濃い橙の縁 Color8(230, 110, 20)（太さ 8）にする。
  - 字は 2 行に収まる大きさにする（上限 52）。
  - 出た瞬間に 0.3 秒、ぽんと弾ませる（いちばん大きいとき 1.25 倍。CR-1169 の宇宙人の弾みと同じ sin の形）。
  - 出るときに効果音 "line"（そろった音。今ある音）と、振動 60 ms・強さ 0.6。
  - 面のクリアのタイル（ピンク）とは、色で見分けられる。
- **直すファイル**:
  - scenes/message_bubble.gd（`show_size_up`・`size_up_box`・`size_up_pop_scale`・`step_pop`、clear_text の戻し）
  - scenes/main.gd（`tick_size_up` で show_tile を show_size_up に替え、音と振動）
- **今ある仕組みを使う**: タイル（show_tile）、字の大きさ（fit_font_size）、効果音 Sound.play_sfx、振動 vibrate。新しい画像・音は要らない。
  - あとで専用の音（例: size_up.wav、「ジャーン」と上がる短い音）を作れば、"line" と差し替えられる。
- **影響**:
  - 面のクリアのタイル・吹き出し・チュートリアルのパネルは変わらない。
  - 0.6 秒待つ・0.8 秒は消さない決まりも変わらない。
  - 既存のテストで変わるものは無い（当て試しで確かめた、下）。

### 案 B「盤のふちが金色に光り、盤の上に大きな『5×5』」 — 手間: 中
- **見た目**:
  - お知らせが出るとき、盤の背景のふち（board_bg_rect）を金色の太い線で 0.8 秒ほど 2〜3 回点滅させる。
  - 同時に、盤の上に大きな字（例 160）で「5×5」を描いて、ふわっと消す。
  - お知らせの札は今のピンクのままか、案 A と組み合わせる。
  - 音と振動は案 A と同じものを足せる。
- **直すファイル**:
  - scenes/board_view.gd（pop_clock でふちの点滅と大きな字の不透明度を出す。CR-1185 の光と同じ作り）
  - scenes/main.gd（tick_size_up から board_view の関数を呼ぶ）
- **今ある仕組みを使う**: board_view の _draw・pop_clock・draw_string（レーダーの数字と同じ）。新しい画像は要らない。
- **影響**:
  - 盤の描き方に足すので、盤のテスト（test_cr_1022 の大きさ・test_cr_1169 の弾み・test_cr_1185 の光）に触らないよう、置き場所に気をつける。
  - 大きな字が宇宙人・数字の上に出るので、見づらさの確かめが要る。
  - 「盤が大きくなった」ことが盤そのもので分かるのが長所。

### 案 C「画面いっぱいのバナーが横から入ってくる」 — 手間: 大
- **見た目**:
  - 画面の真ん中に、横長の帯（幅 1080・高さ 300 ほど）を左から滑り込ませる。帯の上に「5×5 にレベルアップ！」の大きな字と星のきらきら。
  - 1 秒ほど止めてから右へ抜ける。そのあいだ盤は少し暗くする。
  - 専用の効果音と振動。
- **直すファイル**: 新しい scenes/size_up_banner.gd（帯の動きと星の粒）、scenes/main.gd（出す・入力を止める）。
- **要るもの（別に作るもの）**:
  - 帯の画像（例: 1080×300 の PNG、金色のリボン）
  - 星の粒の画像（例: 64×64）
  - 専用の効果音（例: size_up.wav、1 秒ほどのファンファーレ）
- **影響**:
  - 帯が出ているあいだの入力の扱い（CR-1178 の 0.8 秒の決まりとの合わせ方）を決め直す必要がある。test_cr_1178・test_cr_1172 の手順が変わる見込みが大きい。
  - 撮影（.autedev/shot.gd）の絵も変わる。

## 3. 推し: 案 A
**理由**:
- 今いちばん分かりにくいのは、「面のクリアの札と同じピンクの札が、同じ場所にもう一度出る」こと。お知らせだけ色・動き・音・振動を変えれば、「別のことが起きた」と一目で分かる。
- 今ある仕組みだけで小さく直せ、既存のテストも変わらない（当て試しで確かめた）。
- 物足りなければ、案 B（盤のふちの光と大きな 5×5）をあとから重ねられる。

遊び心地はユーザーが選ぶので、推しは参考。

### 当て試しの結果（Godot 4.7.2、main 0ae3435 の写し、GUT を test/unit と test/cr で流した）

| 写し | 当てたもの | 結果 |

- 字の大きさについて:

## 迷った点
1. **音を "line" にした**: お知らせ専用の音が無いため。続けて鳴る面のクリアの音（level_clear）と違う音で、明るい。専用の音を作るなら size_up.wav を足し、`sound.play_sfx("size_up")` に替える CR を別に出す（Sound の SFX_SIZE_UP と match を足す）。
2. **振動 60 ms・強さ 0.6**: 宇宙人を置く 30 ms より長く強く、ぶつかった・× が赤くなる手の 250 ms・0.3（弱め・長め）とは違う、短くはっきりした知らせ。Pixel で強すぎれば 40 ms・0.5 に下げる。
