# Pixel で見つかった 2 つの不具合の原因（main 0ae3435、2026-10-27、クラウドセッション）

コードを読んで調べた。このクラウドには Godot が無く、github.com・tuxfamily からの Godot のダウンロードも、この環境のネットワークの決まりで止められている。そのため probe は流していない（下の「確かめたこと」）。

## 写真の盤の読み（レベル 6）
- game/level_pack.gd のレベル 6 と、写真は合っている。
  - 区域: 行 0 [2,2,2,2,2]、行 1 [0,2,2,2,2]、行 2 [0,2,2,2,1]、行 3 [0,4,4,2,3]、行 4 [0,4,4,3,3]
  - 小惑星: (2,2)・(4,0)
  - レーダー: (1,0) 2・(3,3) 2・(0,4) 1
- 橙は区域 0 で、(0,1)・(0,2)・(0,3) と数字 1 の岩 (0,4) からなる。桃は区域 4 で、(1,3)・(2,3)・(1,4)・(2,4) からなる。
- 写真の盤では、Rules.dead_marks は区域 0 の × 3 つと区域 4 の × 4 つを返す。レーダーの (0,4) は数えない。× だけの組は 2 つある。
- 吹き出しの「× だけの色・行・列があるよ」は、この dead_marks が空でないので出ている。
- 答え（Python に写した Solver で確かめた。答えは 1 通り）は (2,0)・(0,1)・(4,2)・(1,3)・(3,4)。区域 0 の宇宙人は (0,1)、区域 4 は (1,3) なので、どちらの区域も × の付け方が誤っている（警告は正しい）。
- 「音 OFF」のボタン: hud.gd の sound_label() は「押したときにどうなるか」を出す（コメントどおり）。「音 OFF」は今は鳴っている、の意味。

## 1. 音と振動が鳴らない — 考えられる筋の当たり外れ
今の決まり（scenes/main.gd の _refresh）:
- curr_dead = Rules.dead_marks が空でない。
- `sfx_name == "mark" and not last_snapshot.is_empty() and not last_dead and curr_dead` のときだけ "dead" にし、vibrate(250, 0.3) を出す。

| 筋 | 当たり外れ | わけ |
|---|---|---|
| 2 つ目の組では鳴らない | **当たり（本命）** | last_dead は「× だけの組が 1 つでもある」の真偽だけ。1 つ目の組（例: 桃）で鳴ったあと、2 つ目（橙）ができても last_dead が true のままで鳴らない。写真の盤は組が 2 つあるので、少なくとも 1 つは鳴らずにできている。CR-1179 の依頼に「すでに空でないときに × だけの組が増えても鳴らさない」と書いた決まりそのもので、作りの誤りではなく、決まりがユーザーの思いと違う。 |
| 数字の岩を含む区域の数え方の食い違い | **当たり（岩の不具合と重なる筋）** | Rules.dead_marks は、マスの状態が宇宙人かを、岩・レーダーかの判定より先に見る（rules.gd の行・列・区域の繰り返しで `if state == 2 … elif is_asteroid … or is_radar_cell …` の順）。(0,4) の岩に宇宙人がある間（下の 2 の不具合で置ける）、区域 0 は「宇宙人がいる組」で × だけにならない。その宇宙人をダブルタップで取ると、区域 0 が × だけになる。しかしその手の効果音は sfx_for で "clear"（宇宙人が減った）なので、"mark" だけを dead に替える今の決まりでは鳴らない。ユーザーが岩に宇宙人を置いていたので、この筋で橙が鳴らずにできた見込みがある。なお Rules.filled_lines は岩の判定を先にするので、レーダーの宇宙人を数えない。2 つの関数で扱いが違う。 |
| 元に戻す（HUD の戻すボタン、session.undo） | **当たり（同じ型）** | × の上に宇宙人を置いた手を戻すと、× が戻って組が × だけになる。このときも効果音は "clear"（宇宙人が減り、× が増える。clear が先）で、dead に替わらない。× を消した手を戻す場合は "mark" なので、今の決まりでも鳴る（1 つ目なら）。 |
| 進み具合の読み直し（再開） | 当たり（1 段目と同じ型） | 最初の _refresh で last_dead にそのときの盤の真偽が入る。× だけの組がある盤で再開すると、その後の新しい組は鳴らない。 |
| 「音 OFF」で振動も止まる | 外れ | 消音は SoundSettings.apply → AudioServer.set_bus_mute(0, muted) で、音の母線を消すだけ。Input.vibrate_handheld は母線と関係なく出るので、消音でも振動は出る。また写真の「音 OFF」は「今は鳴っている」の意味。 |
| スワイプでまとめて × を付けた手 | 外れ | session.swipe は 1 手で _commit し、効果音は "mark" なので、1 つ目の組なら dead になる（test_cr_1179_main_dead_swipe）。 |
| やり直す（redo） | 外れ | redo は無い。 |
| Android の振動の許可・Sound の setup | 外れ | export_presets.cfg に permissions/vibrate=true（CR-1176）があり、main の _ready で sound.setup() をしている。音も振動も両方出ないので、許可だけの問題ではない。 |
| 効果音の順で dead が負ける | 外れ（この盤では） | × を付ける手は conflicts を増やさず、ヒントも減らさないので、"mark" のまま dead に替わる。 |

まとめ: 主な原因は 1 段目（2 つ目の組では鳴らない決まり）。岩に宇宙人を置けたことで、2 段目（clear の手で × だけになる）の筋も起きうる。どちらが写真の盤で起きたかは、手の順が分からないので決められない。どちらでも、橙・桃の 2 つの組のうち少なくとも 1 つは音も振動も無くできている。

## 2. 数字の岩に宇宙人を置ける — 原因
- game/session.gd の tap・double_tap は `if is_asteroid(x, y) or is_given(x, y): return false` だけで弾いている。is_asteroid は level.asteroids（数字の無い岩）だけを見る。
  - そのため、数字付きの岩（level.radar）では、タップで ×、ダブルタップで宇宙人が付く。
  - swipe も、除くマスは小惑星と最初からある宇宙人だけなので、なぞると数字の岩にも × が付く。
- 見た目と決まりの食い違い:
  - 数字のマスは、もとは数字を出す普通のマスだった。CR-1130 で数字のマスの × の色を変えているので、× を付けられる作りだった。
  - CR-1171 で岩の絵を敷いたので、見た目は数字の無い岩と同じになった。しかし Session の判定は変えていない（CR-1171 の差分は board_view.gd の絵だけ）。
  - 盤の決まりでは、レーダーのマスの宇宙人は Rules.conflicts で赤い。レーダーのマスの × は dead_marks・filled_lines で数えない。付けても得は無い。
- 置ける手:
  - タップ（×）・ダブルタップ（宇宙人）・スワイプ（×）: 置ける。
  - ヒント・答え（apply_hint の next_piece）: 置けない。next_piece は Solver の答えのマスを出す。
    - Python に写した Solver で、固定の 6〜10 面は答えが 1 通りで、レーダーに宇宙人を置く答えは無かった。
    - 作る面も、pick_radar は答えでないマスにだけ数字を置き、make_level は答えが 1 通りの面だけを使う。
- board_view の当たり判定は、マスの位置を返すだけで、岩かどうかは見ない（判定は Session 側）。

### 音（推す: 音A。ユーザーに聞く）
- **音A（推す）**: × だけの組が新しくできるたびに鳴らす。
  - main.gd の last_dead（真偽）を last_dead_marks（前の手のあとの Rules.dead_marks の並び）に替える。
  - 「今の dead_marks に、前に無かった × が 1 つでもある」手で鳴らす。
  - あわせて、"mark" だけでなく "clear" の手（元に戻す・岩の宇宙人を取る）も dead に替える。効果音の順 level_clear > wrong > hint > dead > line > clear > place > mark のとおり。
  - 新しい組ができる手では、その手で × が付いたマス（または戻ったマス）が必ず新しく dead_marks に入る。そのため、マスの差で「新しい組」を漏れなく捕まえられる。
  - 写真の盤のように、橙と桃が順にできれば、2 回とも鳴る。
- 音B: CR-1179 の決まり（空 → 空でないの瞬間だけ）はそのままにし、"clear" の手も dead に替えるだけにする。2 つ目の組では今と同じく鳴らない。

  - 「音 OFF で振動も止めるか」は別の選びなので、今回は変えない。聞くなら、案は「消音でも振動は出す（今のまま、推す）」と「消音なら振動も止める」の 2 つ。
